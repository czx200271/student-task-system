# Student Task Management System

一个帮助学生管理任务的 Web 应用。

## 技术栈

- **前端**: React + Vite + React Router
- **后端**: Node.js + Express
- **数据库**: MongoDB Atlas

## 项目结构

```
/student-task-system
  /client   - React 前端
  /server   - Express 后端
```

## 快速启动

### 1. 启动后端

```bash
cd server
npm install
npm run dev
```

后端运行在 http://localhost:4000

### 2. 启动前端

```bash
cd client
npm install
npm run dev
```

前端运行在 http://localhost:5173

## API 测试

访问 http://localhost:4000/api/health 检查后端是否正常运行。
